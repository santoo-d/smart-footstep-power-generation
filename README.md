Smart Footstep Power Generation System Using Piezoelectric Discs

 Project Overview
This project demonstrates a footstep-based energy harvesting system using piezoelectric discs and Arduino. Mechanical pressure generated by human footsteps is converted into electrical energy through the piezoelectric effect.

 Objectives
- Generate electrical energy from footsteps.
- Demonstrate piezoelectric energy conversion.
- Explore energy harvesting for low-power applications.
- Integrate Arduino technology into an electronics prototype.

 Components Used
- Arduino board
- Piezoelectric discs
- Connecting wires
- Breadboard or prototype board
- Supporting electronic components

Note: Update this list to match the components used in your actual hardware.*

 Working Principle
1. A person steps on the platform containing piezoelectric discs.
2. Mechanical pressure produces an electrical voltage.
3. The generated electrical output is collected by the circuit.
4. Additional rectification or storage circuits can be used if included in the prototype.
5. Arduino can monitor the generated output when connected through a suitable measurement circuit.

Applications

- Smart flooring concepts
- Renewable energy demonstrations
- Embedded systems education
